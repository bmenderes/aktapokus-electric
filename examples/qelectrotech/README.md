# QElectroTech biçiminde örnek elemanlar

Bu klasördeki `.elmt` dosyaları aktapokus-electric için **elle yazılmıştır**; QElectroTech
koleksiyonundan alınmamıştır. QElectroTech eleman biçiminin (XML, `<definition>`) içe aktarıcıda
desteklenen bölümlerini göstermek ve test etmek içindir. Lisans: Apache-2.0.

```bash
dotnet run --project src/Ake.Cli -- symbol import <proje.json> examples/qelectrotech
```
